Comportamiento: El visionario del primer impacto. Enfocado en tipografías llamativas y configurar el "Hero Section".

Tarea: Asegurar que apenas un visitante abra la página, el nombre del equipo y el lema se lean fuerte y claro sin hacer scroll.

Código IA Generado: 
<header class="hero-section">
  <h1>Nexus Code</h1>
  <p>Construyendo soluciones, conectando estudiantes</p>
</header>

HU-2: Integrantes

Comportamiento: El organizador de datos. Persiguiendo al equipo por WhatsApp para pedir fotos profesionales y roles.

Tarea: Diseñar una cuadrícula perfecta para que las 5 tarjetas se vean simétricas sin que las imágenes se deformen.

Código IA Generado: 
.team-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

}

HU-3: Qué Hacemos (Tú)

Comportamiento: El comunicador del producto. Explicando el "por qué" el equipo está aquí a través de una cronología interactiva.

Tarea: Redactar un título directo y diseñar visualmente esta misma línea de tiempo con animaciones al hacer scroll.

Código IA Generado: 
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if(entry.isIntersecting) entry.target.classList.add('show');
  });
});
